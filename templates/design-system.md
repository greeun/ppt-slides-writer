## 1. 팔레트 (CSS 변수 매핑 + 의미 라벨)

색은 반드시 의미 라벨과 함께 쓴다. 같은 색이 장표마다 다른 의미로 쓰이면 의미 라벨 붕괴다.

| 용도 | CSS 변수 | HEX | 의미 라벨 (색=의미 규칙) |
|---|---|---|---|
| 배경 | `--color-bg` | #FFFFFF | 중립 — 기본 캔버스 |
| 표면(카드·블록) | `--color-surface` | #EEF2F6 | 중립 — 정보 묶음 배경 |
| 본문 텍스트 | `--color-text` | #1F2937 | 중립 — 모든 본문 |
| 주 강조 | `--color-primary` | #0F4C81 | 핵심 주장·긍정 수치·CTA 전용 |
| 보조 강조 | `--color-accent` | #B7791F | 주의 환기·비교 기준 강조 전용 |
| 경고/리스크 | `--color-warning` | #C0392B | 위험·손실·감소 수치 전용 |
| 구분선 | `--color-line` | #D9D9D9 | 중립 — 구분선·표 테두리 |

- 팔레트는 6~8색 이내. 그라데이션 전면 금지(단색만) — `references/conversion-rules.md` 금지 1항.
- 강조색을 경고 의미로, 경고색을 긍정 의미로 혼용 금지.

## 2. 타이포그래피 (최대 3패밀리 — lint 체크 7)

시스템 폰트 스택만 허용(웹폰트 금지 — PPTX 변환 시 동일 폰트가 로컬에 있어야 한다).

| 용도 | CSS 변수 | 패밀리(첫 번째 이름이 PPTX에 매핑) | 크기(px) | 굵기 |
|---|---|---|---|---|
| 장표 제목(주장) | `--font-heading` | "Apple SD Gothic Neo", "Malgun Gothic", sans-serif | 40 | 700 |
| 부제(키 메시지) | `--font-heading` | 동일 | 24 | 600 |
| 본문(근거) | `--font-body` | "Apple SD Gothic Neo", "Malgun Gothic", sans-serif | 20 | 400 |
| 캡션·출처 | `--font-body` | 동일 | 12 | 400 |

- 최소 크기: 본문 18px, 캡션·출처 12px (lint 체크 14 — ERROR).
- px→pt 변환: `pt = px × 0.75` (PPTX 기준 제목 30pt / 본문 15pt / 캡션 9pt).

## 3. 여백·간격 리듬

| 토큰 | CSS 변수 | 값(px) | 용도 |
|---|---|---|---|
| 캔버스 안전 여백 | `--space-margin` | 64 | 장표 가장자리 최소 여백 |
| 블록 간격 | `--space-block` | 32 | 요소 묶음 사이 |
| 요소 간격 | `--space-el` | 16 | 인접 요소 사이 |

- 제목 기준선: 모든 장표에서 제목 top 좌표 동일(리듬 유지). 예외는 cover·section-divider.

## 4. radius 계층 (균일 radius 금지 — lint 체크 11)

| 계층 | CSS 변수 | 값(px) | 적용 대상 |
|---|---|---|---|
| 대형 컨테이너 | `--radius-lg` | 16 | 카드·표면 블록 |
| 소형 요소 | `--radius-sm` | 6 | 태그·범례·작은 박스 |
| 직각 | `--radius-none` | 0 | 표·구분선·전면 밴드 |

- 세 계층을 역할대로 구분해 쓴다. 모든 박스가 같은 radius면 AI slop 패턴이다.

## 5. 레이아웃 규칙 (템플릿 리듬)

- 같은 레이아웃 구조 3연속 금지 (기계 lint 대상 아님 — Evaluator 프로브 6이 검출).
- 3컬럼 대칭 카드 그리드(아이콘+제목+설명 ×3)는 1회 이하, 연속 금지.
- 가운데 정렬은 cover·section-divider·cta에서만 기본. 본문 장표는 좌측 정렬 기본.
- 데이터 장표(evidence·financials·comparison)는 수치→해석→시사점이 시각적으로 구분되게.

## 6. 금지사항 (요약 — 전체는 references/conversion-rules.md)

- 그라데이션·그림자·filter·반투명(opacity<1) — 변환 불가 CSS 12항.
- 이모지를 디자인 요소로 사용 금지 (lint 체크 12 — ERROR).
- 보라/인디고 계열(#6366F1~#8B5CF6 대역) 단색 사용 자제 (lint 체크 9 — WARN).
- 팔레트 외 색, 4번째 폰트 패밀리.

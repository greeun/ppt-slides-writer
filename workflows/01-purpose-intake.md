# Workflow 01 — 목적 정의 인테이크 (5질문 + 모드 판별)

오케스트레이터(스킬 메인 세션)가 직접 수행한다. **답변이 모이기 전 Planner 파견
금지(STOP).**

## 1. 5질문 인테이크

AskUserQuestion으로 아래 5가지를 확보한다. **사용자 요청에 이미 답이 있으면 해당
질문은 생략하고 "~로 이해했다"는 확인만** 한다.

| # | 질문 | 확보할 것 |
|---|---|---|
| 1 | 청중 | 누가 듣는가 + 그들의 의사결정 기준 (투자자/임원/실무진/일반) |
| 2 | 목적 | 발표가 끝났을 때 일어나야 하는 일 |
| 3 | 발표 시간 | N분 → 장수 산정 근거(1분당 1~1.5장) |
| 4 | CTA(최종 액션) | 청중이 해야 할 구체적 다음 행동 |
| 5 | 톤 | 격식체(합쇼체) 기본 — 다른 요구가 있는지만 확인 |

**"알아서 해줘" 응답 처리**: 합리적 기본값(사내 보고, 10분, 격식체)을 **명시적으로
선언**하고 진행한다. 단, 스토리라인 승인 게이트(②)는 어떤 경우에도 생략 불가.

**범위 밖 요청 처리**: 전환 애니메이션·영상 임베드 등은 정적 PPTX/PDF 변환 범위
밖임을 1문장으로 안내(금지 CSS 7항 근거)하고, 정적 대안(스틸 컷+링크 표기)을 제시한
뒤 나머지 요청은 정상 수행한다. 스킬 전체 거절 금지.

## 2. 모드 판별

| 모드 | 판별 조건 | 파이프라인 특화 |
|---|---|---|
| 브랜드 템플릿형 | 사용자가 기존 브랜드 자산(PPT/로고/HEX/폰트) 보유 | 디자인 시스템 경로 A 기본 |
| 스토리라인 생성형 | 주제만 있고 시각 자산 없음 | 경로 B(스타일 타일 3안) 기본 |
| 리드마그넷형 | 배포·다운로드 유도 목적(외부 공유물) | CTA·리드마그넷 설계 강화, **배포 전 사람 검토 필수** |

애매하면 위 표를 옵션 비교표로 AskUserQuestion에 실어 사용자가 선택하게 한다.

## 3. 민감정보 사전 경고

인테이크 단계에서 IR·견적·급여·개인정보가 소재로 언급되면 즉시 고지한다:
"민감정보가 포함될 수 있는 자료입니다. 장표에 실릴 범위를 확인해 주십시오."
이후 lint 체크 18·Evaluator 프로브 3이 지속 감시하고, 플래그 발생 시 사용자 명시
확인 없이 최종 게이트를 통과할 수 없다.

## 4. 작업 폴더 생성

사용자 프로젝트에 `slides-work/<deck-slug>/` 를 만들고 status.md를 초기화한다:

```markdown
# status — <deck-slug>
| 단계 | 상태 |
|---|---|
| 1 인테이크 | ✅ |
| 2 모드 판별 | ✅ |
| 3 spec.md (Planner) | ⬜ |
| 4 디자인 시스템 + 게이트 ① | ⬜ |
| 5 스토리라인 + 게이트 ② | ⬜ |
| 6 HTML 스프린트 | ⬜ |
| 7 렌더 게이트 ③ | ⬜ |
| 8 변환 | ⬜ |
| 9 검증 21~26 | ⬜ |
| 10 최종 게이트 ④ | ⬜ |
| 11 배포 안내 | ⬜ |
```

(⬜🔄✅ 이모지는 내부 문서 전용이다 — 장표 내 이모지는 lint ERROR.)

## 5. Planner 파견 (Agent 호출 #1)

`references/planner-prompt.md` 본문에 {WORK_DIR}/{SKILL_DIR}를 치환하고, 인테이크
결과 5항목+모드를 덧붙여 별도 Agent로 파견한다. `SPEC_READY: spec.md` 수신 후
spec.md의 차별화 훅(최소 2개)이 실재하는지 확인하고 다음 단계로 진행한다.

# Examples: 사용 예시 및 에러 처리

## Example Interaction

```
User: "Agentic AI 세미나 기획해줘"

Claude:
1. AskUserQuestion: "기반 커리큘럼이 있나요?"
2. User: "없어, 새로 만들어야 해"
3. AskUserQuestion: "커리큘럼에 포함할 주제들은?"
4. User: "AI-DLC, OpenSpec, MCP"
5. CU 생성 (drafts/)
   - LO 구성만 정의
6. LO 생성 (LOs/)
   - LO-AI-DLC와 Spec-Driven Development
   - LO-OpenSpec으로 0to1 프로젝트
   - LO-점진적 확장과 MCP 서버
7. AskUserQuestion: "세미나 시간과 형식은?"
8. User: "4시간, 온라인"
9. 세미나 프로젝트 생성 (Projects/)
   - 실제 시간 배분
   - 실습 프로젝트 상세
10. 모든 링크 연결

Result:
✅ Created: drafts/CU-Agentic AI 입문/ (LO 묶음)
✅ Created: los/LO-*.md (3개)
✅ Created: Projects/2025-12 Agentic AI 세미나.md (실제 구성)
🔗 Linked: 양방향 링크 완료
```

## Error Handling

### 1. 커리큘럼 없이 세미나 생성 요청

**상황**: 사용자가 세미나 프로젝트 생성을 요청했지만 기반 커리큘럼이 없음

**처리**:
- AskUserQuestion으로 커리큘럼 생성 여부 확인
- 커리큘럼 먼저 생성 또는 기존 커리큘럼 선택

**대화 예시**:
```
User: "다음 주 AI 세미나 만들어줘"

Claude: "기반 커리큘럼이 있나요?

(A) 기존 커리큘럼 사용 (어떤 것?)
(B) 새로 만들기
(C) 커리큘럼 없이 프로젝트만"
```

### 2. 프로젝트에 커리큘럼 내용 복사 시도

**상황**: 커리큘럼의 LO 내용을 프로젝트에 직접 복사하려 함

**처리**:
- 경고: "커리큘럼 내용은 복사하지 않고 링크로 참조합니다"
- 프로젝트에는 실행 정보만 포함

**올바른 방식**:
```markdown
## 기반 커리큘럼

> [[CU-Agentic AI 입문]] (v1.0)

## 세션 구성

| 세션 | LO | 시간 |
|------|-----|------|
| 1 | [[LO-AI-DLC 방법론]] | 1.5H |
```

### 3. 커리큘럼에 시간/프로젝트 상세 포함 시도

**상황**: 커리큘럼에 실제 시간 배분이나 실습 프로젝트 상세를 넣으려 함

**처리**:
- 경고: "커리큘럼은 LO 묶음만 정의합니다. 상세 정보는 프로젝트에 포함하세요"

**구분**:

| 항목 | 커리큘럼 | 프로젝트 |
|------|---------|---------|
| LO 목록 | ✅ | ✅ (링크) |
| 권장 시간 | ✅ (예: "약 4시간") | ❌ |
| 실제 시간 배분 | ❌ | ✅ (예: "10:00-11:30") |
| 실습 프로젝트 | ❌ | ✅ (상세) |
| 참석자 | ❌ | ✅ |

### 4. LO 중복 발견

**상황**: 생성하려는 LO와 비슷한 LO가 이미 존재

**처리**:
```
"이 LO는 [MCP 개념]을 다루려 합니다.
[[LO-MCP 아키텍처]]에서 이미 다루고 있는데, 어떻게 할까요?

(A) 여기서는 링크만 참조
(B) 다른 관점에서 다룸 (비개발자 관점)
(C) 기존 LO 내용을 여기로 이동"
```

# Code Dissector 워크플로우

코드를 한 줄씩 분석하며 모르는 개념을 설명합니다.

## 실행 단계

1. **코드 전체 구조 파악** - 파일 목적, 주요 함수/클래스 식별, 전체 흐름 요약
2. **섹션별 분석** - 코드 블록 + 설명 + 핵심 개념 + 더 알아야 할 것
3. **재귀적 탐구** - 모르는 개념 발견 시 Concept Explorer로 전환, "이 부분 더 설명해줘" 시 해당 섹션 심화
4. **학습 기록** - `templates/code-analysis.md` 형식으로 노트 저장

## 분석 출력 형식

```
[코드 블록]

이 부분이 하는 일:
- ...

핵심 개념:
- 개념1: 설명
- 개념2: 설명

더 알아야 할 것:
- [[개념 링크]]
```

## 트리거

- "이 코드 분석해줘"
- "이 함수가 뭐하는지 모르겠어"
- "한 줄씩 설명해줘"

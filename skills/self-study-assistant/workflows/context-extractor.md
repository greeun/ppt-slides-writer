# Context Extractor 워크플로우

대화에서 학습 내용을 자동으로 추출하고 기록합니다.

## 왜 중요한가

- Gabriel Petersson 방식의 핵심: 대화 자체가 학습 자료
- 질문-답변 맥락이 나중에 복습 자료
- 재귀적 탐구 경로가 지식 구조

## 추출 대상

- 핵심 개념들 (정의, 설명)
- 질문-답변 쌍
- 개념 간 연결 관계
- 인사이트/깨달음
- 탐구 경로 (어떤 순서로 배웠는지)
- 다음에 알아볼 것

## 실행 단계

1. **대화 분석** - 전체 대화에서 학습 관련 내용 식별, 주제별 그룹화
2. **구조화된 추출** - `templates/context-extraction.md` 형식으로 정리
3. **노트 생성** - 추출된 내용을 학습 노트로 저장, 개별 개념은 별도 노트로 분리 가능
4. **연결** - 기존 노트와 링크 연결, 관련 개념 노트 제안

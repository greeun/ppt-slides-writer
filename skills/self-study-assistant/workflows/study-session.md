# Study Session 워크플로우

학습 기록을 추적하고 복습을 관리합니다.

## 실행 단계

1. **세션 시작** - 학습 주제/목표 설정, 기존 학습 기록 확인
2. **학습 진행** - Code Dissector 또는 Concept Explorer 활용, 질문-답변 기록
3. **세션 종료** - 배운 개념 요약, `templates/study-session.md` 형식으로 노트 생성, 복습 일정 제안

## 복습 시스템

### 간격 반복 (Spaced Repetition)

학습 직후 → 1일 후 → 3일 후 → 7일 후 → 30일 후

### 복습 방식

1. **빠른 복습**: 핵심 개념만 훑기
2. **심화 복습**: 코드 다시 분석
3. **응용 복습**: 새로운 예제로 테스트

### 복습 알림

- 세션 종료 시 다음 복습 날짜 제안
- Daily 노트에 복습 항목 추가

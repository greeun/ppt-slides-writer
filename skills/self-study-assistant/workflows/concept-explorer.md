# Concept Explorer 워크플로우

복잡한 개념에서 시작해 기초까지 재귀적으로 탐구합니다.

## 실행 단계

1. **개념 개요 제공** - 한 줄 요약, 왜 중요한가, 핵심 구성요소
2. **의존 개념 매핑** - 현재 개념의 선행 지식 트리 파악
3. **재귀적 탐구 제안** - AskUserQuestion으로 "어떤 선행지식부터 탐구할까요?" 질문
4. **실제 예시/코드 제공** - 개념의 실제 사용 사례와 간단한 코드 예시
5. **학습 기록** - `templates/concept-note.md` 형식으로 노트 저장

## 탐구 깊이 조절

```
Level 0: 최상위 개념 (목표)
    └── Level 1: 직접 의존 개념
        └── Level 2: 2차 의존 개념
            └── Level 3: 기초 개념
                └── Level 4: 수학/CS 기초
```

- 기본: Level 2까지 자동 탐구
- 요청 시: Level 4까지 심화
- 사용자가 "충분해" 하면 중단

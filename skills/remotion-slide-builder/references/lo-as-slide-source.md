# LO를 발표자료 단일 원천으로 집필

발표자료(Remotion 장표)가 빈약해지는 가장 큰 원인은 장표 단계에서 논리를 즉석으로 만들기 때문입니다.
LO를 단일 원천 문서로 충실히 집필하면, 장표는 LO를 시각으로 옮기는 작업으로 단순해집니다.
이 문서는 LO를 발표자료의 원천으로 쓰기 위한 집필 기준을 정리합니다.

> 정보설계·콘텐츠 흐름 기준은 `information-architecture.md`를 함께 참고하십시오.

## 1. LO는 단일 원천 문서

LO 하나에 다음을 모두 담습니다. 강의 원고가 한 곳에 모여 있어야 장표·시연·실습이 어긋나지 않습니다.

| 구성 | 내용 |
|------|------|
| 강의 원고 | 개념을 설명하는 본문. 그대로 읽어도 강의가 되는 밀도 |
| 산출물 작성 기준 | 수강생이 만들 산출물의 입력·필드·상태값·검증 기준 |
| 예제 해설 | 예제 코드·자료의 의미를 한 줄씩 풀이 |
| 시연 런북 | 강사가 시연하는 순서와 확인 지점 |
| 실습 검증 기준 | 수강생이 실습을 완료했는지 판단하는 체크리스트 |

- 근거: 원고·예제·시연·검증이 여러 파일에 흩어지면 다음 회차 갱신 때 누락이 생기고, 장표가 LO와 따로 놀게 됩니다. 단일 원천이면 한 번만 고쳐도 장표에 일관되게 투영됩니다.

## 2. 장표화 가능한 설명 밀도

LO 본문은 그대로 학생에게 보여도 자연스러운 밀도로 씁니다.

- 강사용 메모, 장표화할 때 삭제할 메타 문장("여기서는 ~를 설명할 예정"), 작성 지시는 본문에 넣지 않습니다.
- 본문 한 문단이 장표 한 장의 핵심 메시지로 옮겨질 수 있어야 합니다.
- 근거: 메타 문장이 섞이면 장표화 단계에서 무엇이 콘텐츠고 무엇이 메모인지 매번 가려내야 합니다. 처음부터 학생 기준으로 쓰면 장표화가 발췌·시각화 작업으로 끝납니다.

## 3. LO 표준 절 구조

LO는 다음 절 구조를 따릅니다. **각 절이 발표자료 블록 1개**에 대응합니다.

| 절 | 내용 | 대응 장표 블록 |
|----|------|---------------|
| 위치 | 이 LO가 과정에서 차지하는 자리, 선수 지식 | 도입·맥락 |
| 목표 | 학습 후 무엇을 할 수 있게 되는가 | 학습 목표 |
| 핵심 메시지 | 이 LO에서 가장 중요한 한 문장 | 핵심 메시지 |
| 이론 원고 | 정의·표준 근거·실무 맥락·판단 기준·실패 패턴·연결 | 이론 장표 묶음 |
| 산출물 기준 | 입력·작업·출력·다음 연결, 필드·상태값 | 산출물 장표 |
| 예제 해설 | 예제의 의미를 한 줄씩 풀이 | 예제·코드 장표 |
| 시연 런북 | 시연 순서와 확인 지점 | 시연 장표 |
| 실습·토론 | 실습 절차 또는 토론 주제 | 실습·토론 장표 |
| 검증 체크리스트 | 완료 판단 기준 | 체크포인트 장표 |
| 발표 전환 메모 | 다음 LO·단계로 넘기는 다리 문장 | bridge 장표 |
| 참고 | 출처, 추가 자료 | 출처 표기 |

- 절과 장표 블록이 1:1로 대응하면, 장표 제작자가 LO를 읽으며 어느 절을 어느 장표로 옮길지 바로 판단할 수 있습니다.

## 4. LO 분량 기준

LO 분량은 시간대별로 명시합니다. 아래는 권장 하한입니다.

| LO 시간 | 원고 분량(본문 기준) |
|---------|---------------------|
| 30~60분 LO | 2,000~4,000자 |
| 핵심 LO | 5,000자 이상 |

- 분량이 부족하면 장표가 아니라 **LO를 먼저 보강**합니다.
- 분량을 줄여야 할 때도 발표자료가 아니라 **LO와 운영(시간 배분) 단계**에서 줄입니다. 장표만 줄이면 LO와 장표가 어긋납니다.
- 근거: 장표 분량은 LO에서 파생되는 결과이지 독립 변수가 아닙니다. 원천을 조절해야 장표가 따라옵니다.

## 5. 이론 LO와 실습 LO의 구성 차이

모든 LO에 실습을 강제하지 않습니다. 유형에 따라 구성을 달리합니다.

| 유형 | 강화하는 절 |
|------|------------|
| 이론 LO | 이론 원고(판단 기준·실패 패턴), 리서치·표준 근거, 토론 주제 |
| 실습 LO | 산출물 기준, 시연 런북, 실습 절차(폴더·입력·필드·금지·완료를 step-by-step) |

- 이론 LO에 억지로 실습을 붙이면 흐름이 끊깁니다. 대신 토론·판단 연습으로 능동성을 확보합니다.
- 실습 LO는 폴더 구조, 입력값, 채울 필드, 하지 말아야 할 것, 완료 기준을 단계별로 명시합니다.

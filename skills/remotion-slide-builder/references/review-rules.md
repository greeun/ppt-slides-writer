# 장표 단위 리뷰 절차

발표자료의 경험 문제(표현이 이상하다, 레이아웃이 반복된다, 내용이 어렵다)는 문자열 검색으로는 잡히지 않습니다.
이 문서는 장표를 구성 순서대로 훑으며 점검하고, 우선순위에 따라 고치는 절차를 정리합니다.

## 문자열 검색으로 풀지 않는다

"표현 이상", "레이아웃 반복", "내용 어려움" 같은 경험 문제는 특정 단어를 찾아 바꾸는 방식으로는 해결되지 않습니다.

- composition 순서대로 장표를 하나씩 보며 리뷰 문서를 먼저 작성합니다.
- 근거: 같은 문제가 단어가 아니라 구조에서 나오는 경우가 많아, 문자열 치환은 증상만 가립니다. 장표 단위로 봐야 근본 원인이 드러납니다.

## 수정 순서: P0 → P1 → P2

리뷰와 수정을 분리합니다. 먼저 전체를 리뷰해 문제를 모은 뒤, 아래 우선순위로 고칩니다.

| 우선순위 | 대상 | 설명 |
|----------|------|------|
| P0 | 공통 생성 규칙 | 모든 장표에 영향을 주는 규칙 문제(틀·라벨·문체 등) |
| P1 | 중복 템플릿 제거 | 같은 형태가 반복되는 장표를 다양화 |
| P2 | 난이도·표현 보강 | 어려운 용어 설명 추가, 표현 다듬기 |

수정 후 마무리 절차:

1. 대표 스틸(주요 장표 몇 장)을 렌더해 검증합니다.
2. 전체 PDF를 출력해 최종 확인합니다.

- 근거: P0를 먼저 고치지 않고 개별 장표(P2)부터 손대면, 공통 규칙을 나중에 바꿀 때 작업이 되돌려집니다. 영향 범위가 큰 것부터 고쳐야 재작업이 없습니다.
- 리뷰와 수정을 섞으면 무엇을 고쳤고 무엇이 남았는지 추적이 어려워집니다. 리뷰를 먼저 끝내고 수정에 들어갑니다.

## 6개 점검 항목

각 장표를 아래 6개 항목으로 점검합니다.

| 항목 | 점검 내용 | 통과 기준 |
|------|----------|----------|
| 표현 | 포멀 한국어(합쇼체)인가 | 구어·은유·번역투가 없는가 |
| 템플릿 반복 | 같은 형태가 연속되지 않는가 | 직전 몇 장과 형태가 다른가 |
| 핵심 메시지 | 장표의 요점이 분명한가 | 제목·부제만 봐도 무엇을 배우는지 아는가 |
| 난이도 | 용어가 설명되어 있는가 | 전문용어 첫 등장 시 풀이가 있는가 |
| LO 정합성 | LO 원고와 일치하는가 | 장표가 LO에 없는 내용을 발명하지 않았는가 |
| 앞뒤 연결성 | 흐름이 이어지는가 | 직전·직후 장표와 논리가 끊기지 않는가 |

- 6개 항목은 P0~P2 우선순위와 맞물립니다. 표현·핵심 메시지·LO 정합성은 주로 P0, 템플릿 반복은 P1, 난이도·연결성은 P2에서 보강합니다.
- 근거: 점검 항목을 고정하면 리뷰어마다 기준이 흔들리지 않고, 빠뜨리는 문제 없이 일관된 품질로 검토할 수 있습니다.

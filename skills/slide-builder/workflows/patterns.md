# 디자인 패턴 & 품질 가이드

## 이미지 프롬프트 구성

```yaml
image-prompt:
  concept: "핵심 컨셉 (1줄)"
  composition: "구도, 요소 배치"
  details: "색상, 분위기, 스타일"
  style: "Corporate tech illustration, clean minimalist, 16:9, no text"
```

- hub.md의 이미지 가이드 참조 → 발표 전체 톤앤매너 일치
- 발표마다 일관된 스타일 유지

## 소스 → 슬라이드 변환 패턴

### CU(커리큘럼) → 슬라이드 골격

```
CU 요소                 슬라이드 매핑
───────────────────     ──────────────────
개요                    → 오프닝 title 슬라이드
대상 + 학습 목표        → 오프닝 table 슬라이드
LO 매핑 테이블          → 섹션 분할 기준
  블록/파트             → section 간지 슬라이드
  시간 배분             → 섹션별 슬라이드 수 산정
핵심 메시지             → quote 슬라이드 (클로징)
```

**시간 → 슬라이드 수**: 분당 ~2장 (30초/장). 데모는 분당 ~1장.

### CU → 강사 노트

```
CU 요소          슬라이드 매핑
───────────────────     ──────────────────
기본 정보               → title 슬라이드 meta
환경 설정/체크리스트    → (슬라이드 아님) 강사 준비용
CU 활동 (실습)          → 각 실습 섹션의 notes에 포함
강사 노트               → notes에 분산 배치
```

### 데모 README → 슬라이드

```
README 구조             슬라이드 매핑
───────────────────     ──────────────────
시연 목표               → section 슬라이드 (subtitle = 목표)
시연 순서 Step N        → 1-column 또는 code 슬라이드
  코드 예시             → code 레이아웃
  비교표                → table 레이아웃
핵심 멘트               → quote 슬라이드
백업 플랜               → notes에 포함 ("실패 시: ...")
사전 체크리스트         → (슬라이드 아님)
```

### LO(학습목표) → 콘텐츠 보강

```
LO 요소                 슬라이드 매핑
───────────────────     ──────────────────
핵심 개념               → 본문 불릿, 다이어그램
왜 중요한가             → quote 또는 오프닝 동기 부여
실습 내용               → step-by-step 또는 code
선수 지식               → (사전 확인 슬라이드에 반영)
```

## CU와의 관계

```
CU-주제-기관-YYMMDD.md (강사용 운영 설계서)
    ↓ 링크
slides/hub.md (슬라이드 인덱스)
    ↓ 참조
slides/*.md (실제 슬라이드 콘텐츠)
```

## 분량 가이드라인

| 항목 | 기준 |
|------|------|
| **속도** | 분당 ~2장 (30초/장). 데모/코드 슬라이드는 분당 ~1장 |
| **텍스트** | 슬라이드당 6줄 이내, 불릿 3~5개 |
| **코드** | 10줄 이내, 핵심만. 긴 코드는 하이라이트 |
| **표** | 5행 × 4열 이내 |
| **이미지** | 16:9, 텍스트 없는 일러스트 |
| **key-message** | 모든 슬라이드에 1개 필수 |

## Quality Checklist

### 프로젝트 수준

- [ ] 폴더명 `YYYY-MM-DD-제목` 형식
- [ ] hub.md에 스토리 아크, LO 매핑, 이미지 가이드 포함
- [ ] CU 연결 (표준 또는 커스텀)
- [ ] 전체 시간 ↔ 슬라이드 수 일치

### 섹션 파일 수준

- [ ] frontmatter (section, title, duration)
- [ ] `---` 구분자로 슬라이드 분리
- [ ] 모든 슬라이드에 `<!-- key-message: -->` 있음
- [ ] 모든 슬라이드에 `<!-- notes: -->` 있음
- [ ] 출처 있는 통계/인용은 본문 또는 notes에 명시

### 슬라이드 수준

- [ ] `<!-- layout: type -->` 적절
- [ ] 텍스트 6줄 이내
- [ ] 1슬라이드 = 1메시지
- [ ] 이미지 필요 시 `<!-- image-prompt: -->` 포함

## DO / DON'T

### DO

- key-message를 먼저 정하고 내용 구성
- notes에 **실제 발화할 멘트** 작성
- 출처 명시
- 일관된 이미지 스타일
- 섹션 단위 스토리라인

### DON'T

- 슬라이드에 텍스트 과다 (6줄 초과)
- key-message 없이 내용 나열
- 출처 없는 통계/인용
- 발표마다 다른 이미지 스타일
- 시간 배분 무시 (분당 2장 초과)

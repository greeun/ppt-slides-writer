# Design Tokens

모든 다이어그램에 일관되게 적용하는 기본값.

## 캔버스 & 그리드

```xml
<mxGraphModel dx="1200" dy="900" grid="1" gridSize="10" guides="1"
              page="1" pageScale="1" pageWidth="1100" pageHeight="600">
```

| 토큰 | 기본값 | 범위 | 설명 |
|------|--------|------|------|
| `gridSize` | **10** | - | 스냅 단위 (모든 좌표는 10의 배수) |
| `pageWidth` | **1100** | 1000-1200 | 캔버스 너비 |
| `pageHeight` | **600** | 500-800 | 캔버스 높이 |
| `margin` | **40** | 30-50 | 캔버스 여백 (상하좌우) |

```
┌─────────────────────────────────────────┐
│  40px                              40px │
│  ┌─────────────────────────────────┐   │
│  │         콘텐츠 영역              │   │
│  │      (1020 x 520 사용 가능)      │   │
│  └─────────────────────────────────┘   │
│  40px                                   │
└─────────────────────────────────────────┘
```

## 요소 크기

| 요소 | 너비 | 높이 | 용도 | 예시 |
|------|------|------|------|------|
| **소형 박스** | 70 | 35 | 내부 컴포넌트 | Claude Haiku, Redis |
| **중형 박스** | 120 | 45 | 서비스, 모듈 | FastAPI, Next.js |
| **대형 박스** | 160 | 70 | 주요 서비스 | LangGraph Agent |
| **그룹 박스** | 200-400 | 80-120 | 관련 요소 묶음 | Compute Layer 내 서브그룹 |
| **레이어** | 860-920 | 100-140 | 전체 레이어 배경 | AI Layer, Data Layer |
| **DB 실린더** | 80 | 55 | 데이터베이스 | Aurora, Neptune |
| **아이콘 박스** | 50 | 50 | 작은 아이콘 | 로고, 심볼 |

## 간격 (Spacing)

| 관계 | 기본값 | 범위 | 설명 |
|------|--------|------|------|
| **요소 간 (수평)** | 20 | 15-30 | 같은 행 요소 사이 |
| **요소 간 (수직)** | 15 | 10-20 | 같은 열 요소 사이 |
| **레이어 간** | 20 | 15-30 | 레이어 배경 사이 빈 공간 |
| **그룹 내부 패딩** | 15 | 10-20 | 그룹 테두리 ~ 내부 요소 |
| **레이어 내부 패딩** | 20 | 15-25 | 레이어 테두리 ~ 내부 요소 |
| **화살표 통과 공간** | 40 | 30-50 | 점선/외곽 경로용 여유 공간 |
| **범례 영역** | 40 | 35-50 | 다이어그램 하단 범례 높이 |

## 선 스타일 (Stroke)

| 용도 | strokeWidth | strokeColor | 추가 속성 |
|------|-------------|-------------|-----------|
| **실선 (주요 흐름)** | 2 | #333333 | - |
| **실선 (보조 흐름)** | 1.5 | #666666 | - |
| **점선 (배치/비동기)** | 1 | #666666 | `dashed=1` |
| **점선 (강조)** | 1.5 | 테마색 | `dashed=1` |
| **그룹 테두리** | 2 | 테마색 | - |
| **레이어 테두리** | 1 | 테마색 | - |
| **외곽선 (dashed 그룹)** | 1 | #666666 | `dashed=1` |

## 폰트 크기

| 요소 | fontSize | fontStyle | 용도 |
|------|----------|-----------|------|
| **다이어그램 제목** | 20 | 1 (Bold) | 최상단 제목 |
| **레이어 레이블** | 11 | 1 (Bold) | 레이어 이름 |
| **그룹 레이블** | 10 | 1 (Bold) | 그룹 이름 |
| **박스 레이블** | 10 | 0 (Normal) | 서비스/컴포넌트 이름 |
| **박스 설명** | 9 | 0 (Normal) | 부가 설명 |
| **범례 텍스트** | 8 | 0 (Normal) | 범례 항목 |
| **주석** | 8 | 2 (Italic) | 플로우 설명 |

## 레이어 높이 가이드

| 레이어 내용 | 권장 높이 | 계산식 |
|-------------|----------|--------|
| 텍스트만 | 60-70 | 패딩(20x2) + 텍스트(20-30) |
| 소형 박스 1행 | 80-90 | 패딩(20x2) + 박스(35) + 여유(5-15) |
| 중형 박스 1행 | 90-100 | 패딩(20x2) + 박스(45) + 여유(5-15) |
| 박스 + 설명 1행 | 110-120 | 패딩(20x2) + 박스(45) + 설명(15) + 여유(10-20) |
| 그룹 포함 | 130-160 | 패딩(20x2) + 그룹(80-100) + 여유(10-20) |

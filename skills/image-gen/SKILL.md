# Image Generator

Gemini API와 OpenAI gpt-image 시리즈를 같은 인터페이스로 호출해 한국어 인포그래픽/다이어그램 이미지를 생성하는 스킬.

## 환경

- 한 가지 이상 필요: `GEMINI_API_KEY` 또는 `OPENAI_API_KEY` 환경변수
- Python 3.10+
- 생성 스크립트: 이 스킬 폴더의 `generate.py`
- 프로바이더별 상세: `references/openai.md` (OpenAI gpt-image 시리즈 스펙)

## 핵심 원칙

이 스킬의 품질은 **프롬프트의 구체성**에 달려 있다. 두 프로바이더 모두 지시한 만큼만 그린다.
"적절한 아이콘"이라고 쓰면 모호한 결과가 나오고, "3층으로 쌓인 원통 아이콘, 위에서
아래로 색이 연녹색에서 진녹색으로 진해짐"이라고 쓰면 정확한 결과가 나온다.

프롬프트를 잘 쓰려면 AI가 **맥락을 깊이 이해**해야 한다.
기술 요소의 역할, 상호 관계, 비유, 청중, 심사 기준 — 이런 배경 지식이
레이아웃과 강조점 결정에 직접 영향을 미친다.

## 프로바이더 선택

| 상황 | 권장 모델 | 이유 |
|------|----------|------|
| 한글 텍스트가 많은 인포그래픽·슬라이드 표지 | **OpenAI `gpt2`** (gpt-image-2) | 다국어 텍스트 95~99% 정확. 작은 폰트·곡면·밀집 레이아웃에서도 안정적 |
| 정형 다이어그램(워크플로우/박스/지도) | **OpenAI `gpt2`** | 라벨링과 레이아웃 표준화가 우수 |
| 비용 우선 대량 생성 | **Gemini `2.5`** ($0.039 고정, 정사각만) 또는 OpenAI `gpt2-mini` low ($0.005~0.006) | 초안·반복 검토용 |
| 사진풍 인물·풍경, 일러스트 배경 | **Gemini `3.1`** 또는 `pro` | 나노바나나(네이티브 이미지 생성) 계열이 자연스러움 (Imagen 4 계열은 2026-08-17 서비스 종료) |
| 21:9 등 극단 비율 | **Gemini** | 비율 네이티브 지원 (3.1 계열 10종, 2.5 레거시 14종) |
| 투명 배경 PNG (슬라이드 위 아이콘) | **OpenAI `gpt2` + `--background transparent`** | 네이티브 transparency |
| 멀티턴 일관성 (캐릭터/스타일 유지) | **OpenAI gpt-image 시리즈** | edit API로 점진 수정 |

기본 권장: 핵심 1~2장은 `gpt2 high`, 나머지는 `gemini 3.1` 또는 `gpt2-mini high`로 비용 균형.

## 1단계: 톤 가이드 확인

이미지를 생성하기 전에 **프로젝트 톤 가이드**를 반드시 확인한다.

### 톤 가이드란

프로젝트 내 모든 이미지의 시각적 일관성을 보장하는 짧은 문서.
색상 팔레트, 대비 패턴, 요소 스타일을 정의한다.
한 프로젝트에서 생성하는 이미지 10장이 하나의 디자인 언어를 공유하게 만드는 것이 목적.

### 찾는 순서

1. 프로젝트 `02-작성/diagrams/` 폴더에 `diagram-tone-guide.md` 또는 `tone-guide.md`
2. 프로젝트 루트에 `image-gen.local.md`
3. 프로젝트 `CLAUDE.md` 안에 색상/톤 관련 섹션

### 없으면 만든다

톤 가이드가 없으면 프로젝트 맥락(공고문, 기존 문서, 회사 정보)을 읽고 톤 가이드를 생성한다.
사용자에게 확인받은 후 `02-작성/diagrams/tone-guide.md`에 저장.

**톤 가이드 구조** (이 형식을 따른다):

```markdown
# 다이어그램 톤 가이드

## 색상 팔레트

| 용도 | 색상 | 코드 |
|------|------|------|
| 주 영역 배경 | 진한 {컬러} | #XXXXXX |
| 보조 영역 배경 | 연한 {컬러} | #XXXXXX |
| 부정/경고 강조 | 빨간색 | #C0392B |
| 긍정/솔루션 강조 | 파란색 | #2471A3 |
| 하단 요약 바 | 연한 {컬러} | #XXXXXX |
| 내부 배경 (현재) | 연한 회색 | #F2F2F2 |
| 내부 배경 (제안) | 연한 {컬러} | #XXXXXX |
| 본문 텍스트 | 짙은 검정 | #333333 |

## 톤 규칙

- {대비 패턴: 예) 대비형 그림은 좌측=회색(현재), 우측=녹색(제안)}
- 둥근 모서리 박스, 플랫 아이콘
- 핵심 용어 한/영 병기
- 타이틀은 그림 안에 넣지 않음 (본문에서 [그림 X-Y]로 표기)
- 하단 Key Takeaway 바는 제안서/보고서 삽화에서만 사용 (슬라이드/교육 자료에서는 생략)
- {기관/역할 표시 규칙이 있으면 추가}
```

색상 선정 기준:
- 회사 브랜드 컬러가 있으면 우선 반영
- 정부 과제는 보수적 팔레트 (파랑/녹색/회색 계열)
- 6~10색이면 충분. 더 많으면 산만해진다

## 2단계: 맥락 수집

이미지를 생성하기 전에 충분한 맥락을 확보한다.
맥락이 깊을수록 프롬프트가 정확해지고, 프롬프트가 정확할수록 결과가 좋다.

### 반드시 읽을 것

1. **대상 문서**: 이미지가 들어갈 문서의 해당 섹션 + 앞뒤 섹션
2. **톤 가이드**: 1단계에서 확인한 파일
3. **프로젝트 CLAUDE.md**: 과제 개요, 기술 용어, 심사 배점

### 가능하면 읽을 것 (복잡한 이미지일수록 중요)

- CO-* 회사 정보 파일 (기관별 역할이 있는 경우)
- 기존 다이어그램 프롬프트 파일 (`diagram-prompts.md` 등)
- 공고문/양식 분석 문서

맥락이 부족할 때만 질문한다:
> "이 이미지가 어디에 사용되나요?" (필수 — 용도를 알아야 밀도/크기 결정)

## 3단계: 구상 — guided 또는 freestyle

사용자의 지시 수준에 따라 두 모드로 동작한다.

### 모드 판단

| 신호 | 모드 |
|------|------|
| "알아서", "자유롭게", "적절히", 맥락만 주고 구체적 구성 없음 | **freestyle** |
| 구체적 구성 언급, 옵션 요청, "어떻게 하면 좋을까" | **guided** |
| 벌크 요청에서 "나머지는 알아서" | 첫 장 guided, 나머지 freestyle |

---

### guided 모드

3개 구성 안을 제시하고 사용자가 선택한다.

```
구성 안 A: {한 줄 컨셉}
  - 구조: {레이아웃}
  - 핵심 요소: {무엇을 어떻게}
  - 강조: {어떤 메시지}

구성 안 B: ...
구성 안 C: ...
```

선택 후 상세 계획을 보여준다:

```
이미지 생성 계획
  모델: {2.5/3.1/pro} | 비율: {16:9/...} | 해상도: {1K/2K}
  출력: {파일 경로}

  구성 상세:
  - {영역별 배경색, 내부 요소, 텍스트, 아이콘, 연결선 등}
```

사용자 승인 후 프롬프트 작성 → 생성.

**벌크 요청**: 전체 목록을 먼저 보여주고 한 장씩 순서대로 진행. 일괄 생성 금지.

---

### freestyle 모드

사용자가 맥락과 용도만 주면 AI가 자율적으로 구성하여 바로 생성한다.

**사용자가 주는 것** (최소 입력):
- 어디에 들어갈 그림인지 (문서, 섹션)
- 무엇을 표현해야 하는지 (주제, 핵심 메시지)

**AI가 결정하는 것**:
- 레이아웃, 블록 조합, 영역 구성
- 색상 (톤 가이드에서 가져옴)
- 일러스트, 텍스트 배치, 연결선
- 모델/해상도

**freestyle 흐름**:
1. 맥락 파일을 읽고 배경 지식을 자동 수집
2. 한 줄 요약만 보여주고 바로 생성:
   ```
   freestyle: "{한 줄 컨셉}" — {모델}, {비율}
   ```
3. 결과를 보여주고 피드백 대기
4. "다시" → 다른 구성 / "좋아" → 완료 / 구체적 수정 → 반영 후 재생성

## 4단계: 프롬프트 작성

상세 가이드는 `references/prompt-guide.md` 참조. 핵심 원칙:

1. **자연어 한 덩어리**로 작성 (템플릿 없음)
2. 영역별 배경색(#hex), 텍스트, 아이콘을 구체적으로 기술
3. 화살표/연결선은 별도로 기술
4. 맥락(용도, 청중, 기술 배경)을 프롬프트에 녹인다
5. "표시하지 말 것"은 명시적으로

시각 블록 카탈로그: `references/visual-blocks.md`
제안서용 구도 템플릿: `references/proposal-templates.md` (대시보드 UI, 아키텍처 블록도, 배포도, 데이터 흐름도)

## 5단계: 생성

### 공통 인터페이스

```bash
# Gemini (기본)
python3 .claude/skills/image-gen/generate.py \
  --prompt "조립된 프롬프트" \
  --output "/path/to/output.png" \
  --model 3.1 \
  --resolution 1K \
  --aspect-ratio 16:9

# OpenAI gpt-image-2 (한글 정확도 최상)
python3 .claude/skills/image-gen/generate.py \
  --prompt "조립된 프롬프트" \
  --output "/path/to/output.png" \
  --model gpt2 \
  --aspect-ratio 16:9 \
  --resolution 1K \
  --quality high

# OpenAI mini (저비용 한글 가능)
python3 .claude/skills/image-gen/generate.py \
  --prompt "조립된 프롬프트" \
  --output "/path/to/icon.png" \
  --model gpt2-mini \
  --aspect-ratio 1:1 \
  --quality high \
  --background transparent
```

`--model` 단축키만 바꾸면 프로바이더가 자동으로 결정된다.

### 모델 선택 (2026-08 공식 가격, 정확값)

| 단축키 | 프로바이더 | 1024² high | 16:9 1536×1024 high | 추천 |
|--------|-----------|------------|---------------------|------|
| `2.5` | Gemini | $0.039 (≤1024²) | — (정사각만) | 초안·대량 검토, 비용 우선 |
| `3.1` | Gemini | $0.067 (1K) | $0.067 (1K, 모든 비율) | 기본 품질, 사진/일러스트 |
| `lite` | Gemini | $0.0336 (1K) | $0.0336 (1K, 모든 비율) | 나노바나나 2 Lite — 최저가, 1K 전용 |
| `pro` | Gemini | $0.134 (1K~2K) | $0.134 (1K~2K) | Gemini 최고 품질 |
| `gpt2` | OpenAI | **$0.211** | **$0.165** | **한글 인포그래픽 최상**, 슬라이드 표지 |
| `gpt2-mini` | OpenAI | $0.036 | $0.052 | 한글 OK + 저비용, 아이콘·반복물 |
| `gpt1.5` | OpenAI | $0.133 | $0.200 | 직전 플래그십 (1024²만 강점) |
| `dalle3` | OpenAI | (deprecated) | — | 비권장 |
| `web` | (무료) | 프롬프트만 출력 | — | 대화형 수정용 |

> Batch API 사용 시 모든 모델 50% 할인. 대량 작업에 활용.

> **gpt2 가격 특이점**: 16:9(1536×1024)가 정사각(1024²)보다 **싸다**. 슬라이드용은 16:9 high를 우선 선택.

**추천 워크플로우**: 슬라이드 표지·핵심 인포그래픽은 `gpt2 high` 16:9, 보조 이미지는 `gemini 3.1` 또는 `gpt2-mini high`.

### 지원 비율 / 사이즈

**Gemini**: 고정 비율 + `--resolution`(512px/1K/2K/4K) 조합. `3.1`/`lite`/`pro`는 10종(1:1, 3:2, 2:3, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9), `2.5` 레거시는 14종 전체(극단 배너 비율은 2.5 전용).

| 비율 | 값 | 용도 |
|------|-----|------|
| 정사각형 | `1:1` | 프로필, 아이콘 |
| 사진 세로 | `2:3`, `3:4`, `4:5` | 포트레이트 |
| 사진 가로 | `3:2`, `4:3`, `5:4` | 랜드스케이프 |
| 영상 | `16:9`, `9:16` | 와이드/세로 영상 |
| 울트라와이드 | `21:9` | 파노라마, 슬라이드 콘텐츠 영역 |
| 배너 | `4:1`, `8:1` | 가로 극단 배너 (2.5 레거시 전용) |
| 세로 극단 | `1:4`, `1:8` | 세로 배너 (2.5 레거시 전용) |

**OpenAI**: `--aspect-ratio`+`--resolution`을 자동으로 size 픽셀값으로 매핑한다 (`1536x1024` 등). `--size 1820x780` 형식으로 직접 지정도 가능. `gpt2-mini`는 1024x1024/1024x1536/1536x1024 3종으로 폴백된다(상세는 `references/openai.md`).

**슬라이드 삽화 권장**: SlideLayout 콘텐츠 영역(약 1760x711)에 가장 근접한 비율은 `21:9`(2.33:1). OpenAI에서 21:9는 자동 매핑되며, Gemini는 네이티브 지원.

### OpenAI 전용 옵션

- `--quality low|medium|high|auto` (기본 high) — high가 인포그래픽 권장
- `--output-format png|jpeg|webp` (기본 png)
- `--background transparent|opaque|auto` — 투명 PNG가 필요한 아이콘/일러스트
- `--size WxH` — 비율 매핑을 무시하고 직접 사이즈 지정

### web 모드

`--model web`으로 실행하면 프롬프트를 출력만 한다.
사용자가 gemini.google.com이나 chat.openai.com에 붙여넣어 대화형으로 수정하며 생성.
무료이고 대화형 수정이 가능해서, 복잡한 이미지의 반복 수정에 적합.

## 6단계: 피드백 및 적용

1. 결과를 사용자에게 보여준다
2. 피드백에 따라:
   - "좋아" → 완료
   - "다시" → 프롬프트 조정 후 재생성
   - 구체적 수정 → 해당 부분만 프롬프트에 반영
3. 완성된 이미지를 프로젝트에 적용 (경로 안내)
4. `.prompt.md` 사이드카 파일이 자동 생성됨 (재생성 시 참고용)

## 주의사항

- **한국어**: Gemini와 OpenAI gpt-image 모두 한국어 렌더링 가능. **gpt-image-2가 정확도 최상**(95~99%). Gemini 3.1은 짧은 문구는 양호하지만 긴 문장·작은 글씨에서 깨짐 빈도 있음. Ideogram/Recraft 등은 한국어 불가.
- **비용**: 슬라이드 1세트(10장, 1536×1024) 기준 (2026-08 공식 가격)
  - Gemini 2.5 일괄 (정사각만 가능): 10 × $0.039 = **$0.39**
  - Gemini 3.1 1K 일괄: 10 × $0.067 = **$0.67**
  - gpt-image-1-mini high (16:9): 10 × $0.052 = **$0.52**
  - gpt-image-2 high (16:9): 10 × $0.165 = **$1.65**
  - 혼합 (핵심 2장 gpt2 + 8장 mini high): 2×$0.165 + 8×$0.052 = **$0.75**
  - 혼합 (핵심 2장 gpt2 + 8장 Gemini 3.1): 2×$0.165 + 8×$0.067 = **$0.87**
- **API 제한**: Gemini와 OpenAI 모두 분당·일일 요청 제한이 있다. 대량 작업은 Batch API(50% 할인) 검토.
- **해상도**: Gemini 2.5는 해상도 무관 가격이므로 2K 추천. Gemini 3.1은 1K가 가성비 최적. OpenAI는 quality(low/medium/high)와 size 조합으로 가격이 결정됨.
- **사이드카 프롬프트**: 생성 시 `.prompt.md` 파일이 자동 저장됨. 이후 재생성이나 유사 이미지 생성 시 참고.
- **OpenAI 안전 필터**: 인물 묘사·민감 표현은 거부될 수 있다. 거부 시 프롬프트를 완화한다.
- **상세 레퍼런스**: OpenAI 모델별 세부 스펙·트러블슈팅은 `references/openai.md` 참조.
